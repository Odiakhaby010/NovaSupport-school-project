# NovaSupport meldingenapp

Dit is een eenvoudige desktopapp die ik heb gemaakt in Python met Tkinter.

Met deze app kun je:
- een nieuwe melding toevoegen
- meldingen bekijken
- zoeken op tekst
- filteren op status en prioriteit
- de status van een melding aanpassen
- meldingen opslaan in een JSON-bestand

## Bestanden
De belangrijkste bestanden zijn:
- `app.py`
- `meldingen.json`

## Programma starten
1. Open de projectmap in Visual Studio Code
2. Open `app.py`
3. Start het programma

## Gebruik
- Klik op **+ Nieuwe melding** om een melding toe te voegen
- Gebruik de zoekbalk om op tekst te zoeken
- Gebruik de filters om te filteren op status en prioriteit
- Dubbelklik op een melding of klik op **Bekijk melding** om de details te openen
- In het detailscherm kun je de status aanpassen

## Opslag
De meldingen worden opgeslagen in `meldingen.json`.
Als dit bestand nog niet bestaat, maakt de app zelf een paar voorbeeldmeldingen aan.

## Opmerking
Deze applicatie is gemaakt voor Programming Basics.
